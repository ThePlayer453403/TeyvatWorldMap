# TeyvatWorldMap
TeyvatWorldMap为 <a href=https://github.com/Block-Genshin-Impact/HAW>HomeAndWarp</a> 和 <a href=https://modrinth.com/mod/xaeros-minimap>XaeroMinimap</a> <a href=https://modrinth.com/mod/xaeros-world-map>XaeroWorldMap</a> 间添加了一个《原神》风格的联动

## 前置
### XaeroMinimap >= 26.4.2
### XaeroWorldmap >= 1.44.2
### HomeAndWarp > 1.1.1*

<i>*注：HomeAndWarp具体指的是此<a href=https://github.com/Block-Genshin-Impact/HAW/pull/1>PR</a>**后的版本，目前没有正式版</i>

<i>**注：如果手动构建该版本会看到版本号为1.1.0，这是因为在更新1.1.1时，版本号没更新</i>
